## Retrieval caveats

During this pass, direct page opens for some JavaScript-heavy ECI / voter pages returned `406 Not Acceptable`, timeouts, or an application-shell message in the web retrieval environment. The pages were still researched via official search-indexed content and user-provided HTML where available. Direct retrieval of `https://ecinet.gov.in/` returned a 502 gateway error. The ECI homepage HTML and ECI public descriptions refer to the host `https://ecinet.eci.gov.in/`.
